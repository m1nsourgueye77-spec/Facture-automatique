# 📄 Facture Automatique

Application web de gestion de factures développée en HTML, CSS et JavaScript.

## 🚀 Fonctionnalités

- ✅ Création de factures professionnelles
- ✅ Gestion des informations de l'entreprise
- ✅ Gestion des clients
- ✅ Ajout dynamique de produits
- ✅ Calcul automatique :
  - Sous-total
  - Remise
  - TVA
  - Total TTC
- ✅ Génération d'une facture en PDF
- ✅ Interface responsive
- ✅ Stockage local des données

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- jsPDF

Clonez le dépôt :

```bash
git clone https://github.com/VOTRE-UTILISATEUR/VOTRE-DEPOT.git
```

Puis ouvrez simplement **index.html** dans votre navigateur.

## 📌 Fonctionnement

1. Renseigner les informations de l'entreprise.
2. Ajouter le client.
3. Ajouter les produits.
4. Calcul automatique des montants.
5. Générer et télécharger le PDF.
